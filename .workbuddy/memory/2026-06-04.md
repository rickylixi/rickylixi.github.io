## 已修复（本次）

### 配置层
1. **删除 `_config.yml` 废弃的 `theme_settings:` 段**（第 134-144 行）
   - 不是 Jekyll 标准配置键，值与 `styles.css` 实际变量不一致，属于死配置
2. **删除 `_config.yml` 废弃的 `api_timeout:`**（第 150 行）
   - 无任何插件或模板读取此值，`visitor-counter.js` 有自己的 `REQUEST_TIMEOUT_MS` 常量
3. **删除 `_config.yml` exclude 中对不存在文件的引用**（第 40 行 `_config_sitemap.yml`）
   - 文件不存在，排除条目无效

### Service Worker 层
4. **删除 `sw.js` 未使用的 `OFFLINE_CACHE` 常量**（第 7 行）
   - 声明后从未被引用
5. **删除 `sw.js` Push Notification 代码**（第 252-291 行）
   - 注册了 `push` / `notificationclick` 事件处理器，但全站无任何地方调用 `Notification.requestPermission()` 或 `registration.showNotification()`
6. **简化 `sw.js` Background Sync 处理器**（第 241-250 行）
   - 原处理器只返回空 `Promise.resolve()`，未实现任何实际同步逻辑；保留日志输出，移除无用的注释

### 数据层
7. **清理 `_data/teaching.yml` 残留的 `size:` 字段**（共 8 处）
   - 上次修复已删除模板中的 `{{ resource.size }}` 渲染逻辑，但 yml 数据里的 `size:` 字段未同步清理

### 代码质量
8. **修复 `sw.js` 废弃的 `substr()` 方法**（第 36 行）
   - 改为 `substring(11, 19)`，符合 ECMAScript 规范
   - 注意：此行在 `DEBUG_SERVICE_WORKER = false` 分支内，实际不会执行
9. **删除 `package.json` 错误的 `main` 字段**
   - `sw.js` 不是 npm 包的主入口，此字段无意义

## 未修复（需进一步决策）

### 中优先级
- **`sw.js` Background Sync 处理器是空实现** — 如需离线分析数据同步功能，需实现实际逻辑；否则可彻底删除此事件监听器
- **Inline Critical CSS 与 `styles.css` 变量值不一致风险** — `default.html` 第 20 行 inline CSS 的 `--font-sans` 值与 `styles.css` 第 25 行略有差异（`Neue` vs `Neue`），虽然后加载的 `styles.min.css` 会覆盖，但维护时容易遗漏

### 低优先级
- **`styles.css` 中 `--font-sans` 值包含字面量单引号** — `--font-sans: 'Inter', ...` 中的单引号是值的一部分，替换后字体族解析可能异常（但实测未触发问题）
- **`teaching.html` 未设置 `math: true`** — 页面包含 `.tex` 文件链接但不需要渲染数学公式，无需修改
