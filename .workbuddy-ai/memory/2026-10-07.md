# 2026-10-07

## 修复 CI 的 npm audit 失败（high 级别）

- 原因：purgecss@7 → postcss-selector-parser@6.1.4 (<7.1.6, GHSA-rj75-hqrm-r3gf)、postcss → source-map-js@1.2.1 (GHSA-68fv-2mgg-jv7q, high)。
- 方案：在 `package.json` 加 `overrides`：`postcss-selector-parser: ^7.1.6`、`source-map-js: ^1.2.2`，purgecss 保留 `^7.0.2`。
- 关键坑：升级到 purgecss@8 会引入 fast-glob → micromatch → braces，而 braces (GHSA-vfj7-8cjw-p6xm / CVE-2026-93687) 目前**无修复版本**，反而会让 CI 的 `npm audit --audit-level=high` 继续失败（4 high）。故维持 v7。
- 验证：`npm ci` → found 0 vulnerabilities；`npm run build` 成功，styles.min.css 与 git 中已提交版本字节一致（说明 v7 覆盖不影响 purge 结果）；`npm test` 通过。
