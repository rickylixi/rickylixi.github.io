论述题: 任选两题, 每题50分.
%\pdfbookmark[1]{Contents}{anchor}%\tableofcontents
\begin{enumerate}
 \item 休谟问题在机器学习中有什么体现? 
 \item 通用归纳模型与因果发现因果推断有什么关系? 
 \item 相关性与因果有什么关系? 
 \item 你认为``实际因果''的合适定义是什么? 
 \item 如何刻画``意图''? 
 \item 因果与责任有什么关系? 反事实推理可以帮助界定责任吗? 
 \item 你对``向下因果''有什么看法? 
 \item 请结合案例用中介分析的技巧分析一类可能涉及不公平的社会现象. 
 \item 如何界定机器的``道德主体''Moral Agent 地位? 或 Moral Patient 地位?
 \item 如何看待用``目标导向的机制适应性''刻画Agency?
 \item 如何看待``压缩即智能''的观点? 
 \item 什么是大语言模型的``幻觉''问题? 产生原因是什么? 怎么减少``幻觉''? 可以根除``幻觉''吗?
 \item 你认为``有效复杂性''的内涵是什么? 在人工智能中的作用是什么? 
 \item 你认为``随机性''会在人工智能中扮演什么角色? 
 \item 你是如何看待``涌现''的? 怎么度量``因果涌现''? ``因果涌现''独立于观察者吗? 
 \item``动力因''闭合是``生命''的本质特征吗? 如何看待``生命''与``智能''的关系? 
 \item 请结合相关算法, 阐述``遗忘''对学习的作用. 
 \item 意识是智能的必要条件吗, 如何看待二者的关系? (结合某种意识理论讨论)
 \item 自由意志是智能的必要条件吗, 如何看待二者的关系? 
 \item 请简单介绍一种你了解的不确定性推理的方法并阐述其面临的困难. 
 \item 如何看待 (G\"odel, Chaitin, Legg 等人的)不完备性定理与人工智能的关系? 
 \item 如何看待图灵-丘奇论题与人工智能的关系? 
 \item 知识表示的``本体''指什么? 如何构建? 
 \item 对于人工智能来说, ``语义''指什么? 语词如何获得``意义''? 词向量嵌入技术能否帮助捕捉语义? 大语言模型有``语义''吗? 
 \item``世界模型''World Model 的标准是什么?
 \item 如何看待由生成对抗网络 GAN (或 Stable Diffusion 或 Sora)生成的艺术作品的美学价值? 
 \item 你认为符号主义与联结主义会以什么样的方式结合?
 \item 如何理解通用人工智能的``通用性''?
 \item 机器可以进行完全的自我升级吗? 
 \item 如何看待能够对``策略''或``效用函数''进行自我修改的Agent?
 \item 如何理解智能与目标正交性论点? 
 \item 如何理解工具性子目标趋同论点? 
 \item 如何理解``Wireheading''问题? 你认为应该怎么解决? 
 \item 古德哈特定律会导致什么样的人工智能伦理问题? 如何解决? 
 \item 基于人类反馈的强化学习 RLHF 是处理人工智能对齐问题的合适方法吗? 造成``谄媚''咋办?
 \item 人工智能对齐问题的解决是否应该贯彻以人为本的原则?
 \item 如何用 FDT 决策理论处理可扩展监督问题? 
 \item 如何看待``Reward is enough''假设? 
 \item 存在普适的价值观吗? 你认为人工智能应该追求什么样的价值观?
\end{enumerate}
